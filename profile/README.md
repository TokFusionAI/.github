# TokFusionAI

**AI for tokamak fusion, built on EAST.**

## About Us

We are the TokFusionAI team at the Institute of Plasma Physics, Chinese Academy of Sciences (ASIPP). We develop AI tools for the EAST tokamak, using machine learning on real experimental data to help understand, predict, and control fusion plasmas.

### Research Areas

- Discharge modeling and prediction
- Discharge scenario design
- Diagnostic data processing
- LLMs for fusion
- Data infrastructure
- Fusion engineering

## 关于我们

我们是中国科学院等离子体物理研究所（ASIPP）的 **TokFusionAI** 团队，主要基于 **EAST 托卡马克** 开发 AI 工具，利用真实实验数据，用机器学习方法帮助理解、预测和控制聚变等离子体。

### 研究方向

- 放电建模与预测
- 放电方案设计
- 诊断数据处理
- 大模型赋能聚变
- 数据基础设施
- 聚变工程
